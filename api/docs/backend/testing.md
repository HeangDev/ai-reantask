# Backend Testing

## Test Types

### Unit Tests

Test isolated business logic.

### Feature Tests

Test application behavior and workflows.

### API Tests

Test:

- Authentication
- Authorization
- Validation
- Successful responses
- Error responses
- Resource behavior

### Database

Test:

- Migrations
- Relationships
- Constraints
- Important database behavior

## Requirements

Every important business feature should have appropriate tests.

Authorization and validation should be tested explicitly.
