# UI / UX Requirements

## Design System

Use the existing design system consistently.

Reuse:

- Buttons
- Inputs
- Selects
- Tables
- Cards
- Dialogs
- Alerts
- Tabs
- Navigation
- Typography
- Spacing

Do not create duplicate components when an existing component
can satisfy the requirement.

## Responsive Design

The application must support:

- Mobile
- Tablet
- Desktop

Responsive behavior must be considered for:

- Navigation
- Tables
- Forms
- Dialogs
- Cards
- Layouts

## UI States

Data-driven screens should provide:

- Loading state
- Empty state
- Error state
- Success state

## Forms

Forms should provide:

- Clear labels
- Validation feedback
- Loading state
- Submit feedback
- Server error feedback

## Accessibility

Follow accessible web practices:

- Use semantic HTML.
- Provide labels for form controls.
- Provide meaningful alternative text.
- Support keyboard interaction.
- Preserve visible focus states.
- Do not rely on color alone to communicate meaning.
