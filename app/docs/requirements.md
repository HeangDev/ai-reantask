# Functional Requirements

## 1. Authentication

The application should provide:

- Login
- Logout
- Authentication state
- Protected routes
- Authentication error handling

## 2. Dashboard

The dashboard should provide:

- Summary information
- Relevant statistics
- Recent activities
- Loading state
- Empty state
- Error state

## 3. Student Management

Users should be able to:

- View students
- Search students
- Filter students
- View student details
- Create students
- Edit students
- Delete students

## 4. Teacher Management

- View teachers
- Search teachers
- Filter teachers
- View teacher details
- Create teachers
- Edit teachers
- Delete teachers

## 5. User Management

Users should be able to:

- View users
- Search users
- Filter users
- View user details
- Create users
- Edit users
- Delete users

## 6. Role Management

Users should be able to:

- View roles
- Search roles
- Filter roles
- View role details
- Create roles
- Edit roles
- Delete roles

## 7. Student Management

Students should be able to:

- Join a class using a code
- View assignments
- See deadline
- Upload homework
    - PDF
    - DOCX
    - Images
    - ZIP/code
- Submit / Resubmit
- See submission status
- Receive teacher feedback
- See grade/score
- Get notifications for deadlines

## 8. Teacher Management

Teachers should be able to:

- Create classes
- Create assignments
- Set:
    - Title
    - Description
    - Deadline
    - Maximum score
    - Allowed file types
    - Maximum file size
- View submitted homework
- Download/view files
- Grade students
- Add comments/feedback
- Request resubmission
- Track late submissions

## 9. General Requirements

Every data-driven feature should handle:

- Loading
- Success
- Empty
- Error

Every form should handle:

- Initial state
- Validation
- Submission
- Server errors
- Success feedback
