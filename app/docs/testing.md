# Testing

## Goals

Tests should verify behavior rather than implementation details.

## Test Areas

### Components

Test important user-visible behavior.

### Forms

Test:

- Valid input
- Invalid input
- Validation messages
- Submission
- Server errors

### Features

Test important user workflows.

### API Integration

Test loading, success, empty, and error states where appropriate.

## Verification

After implementation, run the project's available:

- Type checking
- Linting
- Unit tests
- Component tests
- Integration tests
- Build

Do not mark a task as verified if required checks failed.
