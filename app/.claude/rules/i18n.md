# Internationalization (i18next)

## 1. Setup

- `i18next` + `react-i18next` + `i18next-browser-languagedetector` + lazy backend (`i18next-resources-to-backend`).
- Locales: `en` (default, fallback) + others (see requirements open questions).
- Detection order: `uiStore.locale` → `localStorage` → `navigator.language` → `en`.
- Set `<html lang>` and `dir` on change.
- Files: `shared/i18n/locales/<lng>/<namespace>.json`.

## 2. Namespaces

`common` (buttons, generic), `validation`, `errors`, `auth`, `assignments`, `submissions`, `review`, `admin`, `notifications`.
Load feature namespaces lazily with the route.

## 3. Keys

- Format: `feature.section.element` in lower camelCase: `review.criteria.overrideReason.label`.
- Describe meaning, not text. No sentences as keys.
- Never concatenate translated fragments; use interpolation: `"deadline": "Due {{date}}"`.
- Plurals via i18next suffixes (`_one`, `_other`; add `_few`/`_many` per locale).
- Rich text: `<Trans i18nKey="..." components={{ b: <strong /> }} />`.
- Enums map: `t(\`submissions.status.${status}\`)` — add a type-safe helper and a test that every enum value has a key.

## 4. TypeScript

Augment `i18next` `CustomTypeOptions` with `resources` from the `en` JSON → autocomplete & compile-time key checking.

## 5. Formatting

Use `Intl` through helpers (`formatDate`, `formatNumber`, `formatRelativeTime`) that read the current locale. No hard-coded date formats or decimal separators.

## 6. Rules

- **No user-facing hardcoded strings** in JSX, `aria-label`, `title`, `placeholder`, toast, or Zod messages.
- Backend errors return `code`; map to `errors.<code>` keys. Never show raw server messages.
- AI-generated feedback text is **content**, not UI: render as received (it may be in the student's language); don't translate automatically.
- Allow ~30–40 % text expansion in layouts; avoid fixed-width buttons.
- Avoid text in images.

## 7. Workflow

1. Add key to `en` first.
2. Run `npm run i18n:check` (script compares key sets across locales, finds unused/missing keys).
3. Translators fill other locales; CI fails on missing keys in release branches.
